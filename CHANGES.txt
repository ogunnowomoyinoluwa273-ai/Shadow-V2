SHADOW LYRICS FIX  (built on Shadow-V2-main.zip)

INSTALL: stop Shadow, copy these 5 files over your project (same folders), keep your own .env, npm start.
Then check it live from your PC:   .lyrics Contigo - BoyWithUke     and     Shadow, what does Contigo say?

WHY IT "DIDN'T WORK"
 1. By design, .lyrics never returns lyric text. It finds the song on LRCLIB and replies with the song/artist and a Genius
    search link; the code throws away the lyric text LRCLIB sends back. If you expected the words in WhatsApp, that is why.
    (Unchanged on purpose: LRCLIB's text is community-submitted, not licensed for redistribution. Licensed full text needs
    a paid provider key, e.g. Musixmatch.)
 2. "Shadow, give me the lyrics to X by Y" sent the whole sentence, including "by", to LRCLIB as one keyword string.
    Now title and artist are sent as separate fields (track_name / artist_name, which LRCLIB documents), with keyword
    fallbacks (max 3 calls), and titles containing "by" ("Stand By Me") still work.
 3. "Shadow, what does X say?" was not recognised, so it fell through to the AI. Now it routes to .lyrics (not for he/she/it/
    that/the message, and not when you reply to a message).
 4. The AI had no rule against writing lyrics from memory. It now has one and points to .lyrics instead.
 5. An exact title-and-artist match now wins over covers/remixes/other artists; Shadow only asks "which one?" when the
    artist is missing or really ambiguous.

NOT VERIFIED: live calls to LRCLIB (my sandbox has no internet). Everything above is tested with simulated responses.
NOTE: only the owner and sudo users can run commands, so a normal group member typing .lyrics is ignored by design.
